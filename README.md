# همراه پروژه | Hamrah Project

اپلیکیشن فارسی اندروید برای برنامه‌ریزی و کنترل پروژه‌های عمرانی، صنعتی و زیرساختی.

## قابلیت‌های موجود در این نسخه
- رابط فارسی و راست‌چین مبتنی بر Jetpack Compose
- ثبت نام پروژه در اولین اجرا
- الگوی شروع پروژه مخزن بتنی ۲۰۰۰ مترمکعبی با فعالیت‌های نمونه
- ثبت محلی فعالیت‌ها، برنامه، پیشرفت، هزینه‌ها و ریسک‌ها
- انتخاب و نگهداری فایل‌های پروژه در فضای خصوصی برنامه
- دستیار متنی با ورودی گفتاری فارسی (از طریق سرویس تشخیص گفتار دستگاه) و خواندن پاسخ با موتور گفتار دستگاه
- اتصال سرور به Gemini API با حالت Free Tier و بدون fallback پولی
- ساخت APK از طریق GitHub Actions

## ساخت APK
از بخش Actions گردش‌کار Build Hamrah Project APK را اجرا کن. پس از موفقیت، فایل APK در بخش Artifacts همان اجرای workflow قرار می‌گیرد.

## راه‌اندازی Gemini رایگان
راهنمای کامل در cloudflare-worker/README.md است. کلید API فقط باید به‌صورت Secret با نام GEMINI_API_KEY در Cloudflare ذخیره شود. هرگز کلید را داخل اپ یا GitHub commit نکن. Billing پروژه Google را فعال نکن تا استفاده در Free Tier باقی بماند.

## محدودیت‌های نسخه فعلی
این نسخه پایه عملیاتی است، نه محصول کامل سازمانی. تحلیل خودکار PDF/Word/Excel، OCR، استخراج داده با ارجاع صفحه و بند، تطبیق مغایرت اسناد، تولید خودکار WBS از پاسخ AI، گانت و محاسبه مسیر بحرانی، چندکاربره و همگام‌سازی ابری هنوز نیازمند توسعه و آزمون‌اند. اطلاعات قراردادی و مالی باید پیش از ثبت نهایی توسط کاربر تأیید شوند.

## حریم خصوصی
در Gemini Free Tier ممکن است محتوای ارسالی برای بهبود محصولات Google استفاده شود. اسناد محرمانه را بدون مجوز سازمانی ارسال نکنید؛ ابتدا اطلاعات حساس را حذف یا ناشناس‌سازی کنید.
